## 1. Writing shell scripts

A **shell script** is a text file containing shell commands. The `.sh` suffix is only a convention; what matters is how you run the file.<br>

`vi gen_files.sh` - Create or edit the script (use any editor you like).<br>

`bash gen_files.sh` - Run the script in a **new** bash process. When it finishes, your current shell is unchanged (for example, a `cd` inside the script does not move your interactive session).<br>

`source gen_files.sh` or `. gen_files.sh` - Run the script **in the current shell**. Variables and `cd` from the script affect this session.<br>

### Example

**`gen_files.sh`:**

```sh
mkdir -p ~/temp
cd ~/temp
touch file{1..10}.txt
echo done
```

`bash gen_files.sh` - Ensures `~/temp` exists, changes into it, creates `file1.txt` through `file10.txt`, then prints `done`.<br>
