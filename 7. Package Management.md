## 1. Package management & APT

**APT** (Advanced Package Tool) is how Debian-based systems install and update software from repositories. Commands that change installed packages or the package index usually need `sudo`.<br>

### Install, remove, search

`sudo apt install <package>` - Install a package and its dependencies.<br>

`sudo apt install aptitude` - Example: install **aptitude**, a terminal UI for browsing and managing packages.<br>

`sudo apt remove <package>` - Uninstall a package; configuration files may remain.<br>

`sudo apt purge <package>` - Uninstall a package and remove its configuration files.<br>

`sudo apt search <keyword>` - Search names and descriptions of available packages.<br>

`apt show <package>` - Show version, description, and dependencies from the package index.<br>

### Refresh lists and upgrade

`sudo apt update` - Download fresh package lists from your configured repositories (does not upgrade installed packages by itself).<br>

`apt list --upgradeable` - List packages that have a newer version available.<br>

`sudo apt upgrade` - Upgrade all installed packages that can be upgraded without removing packages.<br>

`sudo apt upgrade <package>` - Upgrade only that package, if an update exists.<br>

`sudo apt full-upgrade` - Upgrade and allow installing or removing other packages when needed to satisfy dependencies (stronger than plain `upgrade` in tricky situations).<br>

### Inspect and tidy

`apt list --installed` - List packages currently installed on the system.<br>

`apt list` - List packages known from the cache (very long; often used with a filter or `--installed`).<br>

`sudo apt autoremove` - Remove packages that were installed only as dependencies and are no longer required.<br>
