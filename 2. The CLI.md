## CLI Directories & Arguments

`pwd` - Print the current working directory.<br>
`cd` - Change to another directory.<br>
`cd ..` - Move up one directory level.<br>
`cd /folder` - Move to an absolute path (replace `/folder` with your target path).<br>
`<command> --help` - Show help and available options for a command.<br>
`ls` - List files and folders in the current directory.<br>
`echo "something"` - Print text to the terminal (`echo something` also works).<br>
`which <command>` - Show the path of the command executable being used.<br>

## Flags

`ls -l` - Show a detailed (long) list.<br>
`ls -a` or `ls --all` - Show hidden files/folders too.<br>
`ls -la` - Combine `-l` + `-a` (detailed list + hidden files).<br>
`ls --all --size` - Show all files/folders and their size in blocks.<br>
`ls -as` - Short form of `ls --all --size` (`-a` + `-s`).<br>
`ls --ignore=NAME` - Ignore one file/folder in the output.<br>
`ls -I NAME1 -I NAME2` - Ignore multiple names in the output.<br>
`ls folder/` - List contents of `folder/` without moving into it.<br>

## CLI Search

`cd ~` - Go to your home directory.<br>
`cd /` - Go to the root directory.<br>
`Up/Down Arrow` - Browse command history.<br>
`<command>` + `Tab` - Try autocomplete for commands/options.<br>
`cd` + `Tab` - Show folders you can move into.<br>
`Ctrl + r` - Search through command history.<br>

## Bash History

`!!` - Run the previous command again.<br>
Example: `sudo !!` (useful when the last command needed admin privileges).<br>

`clear` or `Ctrl + l` - Clear the terminal screen.<br>

## CLI Shortcuts

`Ctrl + a` - Move to the beginning of the line.<br>
`Ctrl + e` - Move to the end of the line.<br>
`Ctrl + k` - Delete everything after the cursor.<br>
`Ctrl + u` - Delete everything before the cursor.<br>
`Ctrl + y` - Paste (yank) the last deleted text.<br>
`Ctrl + r` - Search backward through command history.<br>

## Signals

`Ctrl + c` (`SIGINT`) - Interrupt the foreground process (mnemonic: **C**ancel).<br>
`Ctrl + d` (end of file, `EOF`) - Signal end-of-input; often exits a shell, REPL, or program reading stdin (mnemonic: **D**one with input).<br>
