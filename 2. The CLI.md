## CLI Directories & Arguments

`pwd` - Print the current working directory.
`cd` - Change to another directory.
`cd ..` - Move up one directory level.
`cd /folder` - Move to an absolute path (replace `/folder` with your target path).
`<command> --help` - Show help and available options for a command.
`ls` - List files and folders in the current directory.
`echo "something"` - Print text to the terminal (`echo something` also works).
`which <command>` - Show the path of the command executable being used.

## Flags

`ls -l` - Show a detailed (long) list.
`ls -a` or `ls --all` - Show hidden files/folders too.
`ls -la` - Combine `-l` + `-a` (detailed list + hidden files).
`ls --all --size` - Show all files/folders and their size in blocks.
`ls -as` - Short form of `ls --all --size` (`-a` + `-s`).
`ls --ignore=NAME` - Ignore one file/folder in the output.
`ls -I NAME1 -I NAME2` - Ignore multiple names in the output.
`ls folder/` - List contents of `folder/` without moving into it.

## CLI Search

`cd ~` - Go to your home directory.
`cd /` - Go to the root directory.
`Up/Down Arrow` - Browse command history.
`<command>` + `Tab` - Try autocomplete for commands/options.
`cd` + `Tab` - Show folders you can move into.
`Ctrl + r` - Search through command history.

## Bash History

`!!` - Run the previous command again.  
Example: `sudo !!` (useful when the last command needed admin privileges).

`clear` or `Ctrl + l` - Clear the terminal screen.

## CLI Shortcuts

`Ctrl + a` - Move to the beginning of the line.
`Ctrl + e` - Move to the end of the line.
`Ctrl + k` - Delete everything after the cursor.
`Ctrl + u` - Delete everything before the cursor.
`Ctrl + y` - Paste (yank) the last deleted text.
`Ctrl + r` - Search backward through command history.
