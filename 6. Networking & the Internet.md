## 1. SSH & Secondary Machine

**Multipass** runs a small Ubuntu VM on your computer so you can practice on a second Linux system without extra hardware. Install it from your distro's packages or [multipass.run](https://multipass.run/).<br>

`multipass launch` - Download the default image and start a VM.<br>

`multipass launch --name <vm-name>` - Create a VM with a specific name.<br>

`multipass shell <vm-name>` - Open an interactive shell inside that VM.<br>

`sudo useradd -s <shell> -m -g <group> <username>` - Create a user with login shell `<shell>`, a home directory (`-m`), primary group `<group>`, and username `<username>`.<br>

`sudo useradd -s /bin/bash -m -g ubuntu okshan` - Example: user `okshan`, primary group `ubuntu`, shell `bash`, with a home directory.<br>

`sudo passwd <username>` - Set or change the password for that user.<br>
