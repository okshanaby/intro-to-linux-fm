## Interacting with Files

## 1. Reading Files

`less filename.txt` - View a file page by page (good for large files).

Useful controls inside `less`:
- `Up/Down Arrow` - Move line by line.
- `Space` - Next page.
- `b` - Previous page.
- `/word` - Search for `word`.
- `n` - Next search result.
- `q` - Quit `less`.

`man <command>` - Show the full manual page for a command.

`cat filename.extension` - Print the full file content to the terminal.

`tail filename.extension` - Show the last lines of a file (default: 10).
`tail -n 3 textfile.txt` - Show the last 3 lines.
`tail -f textfile.txt` - Follow new lines in real time (useful for logs).

`head filename.extension` - Show the first lines of a file (default: 10).
`head -n 3 textfile.txt` - Show the first 3 lines.

## 2. Creating & Moving Files

`mkdir <foldername>` - Create a new directory.
`mkdir -p <folder1/folder2/folder3>` - Create nested directories in one command.

`touch <filename.extension>` - Create a file if it does not exist; if it exists, update its timestamp.

`rm filename.extension` - Delete a file.
`rm -r foldername` - Delete a folder and its contents recursively.
`rm -rf foldername` - Force delete a folder and its contents (no prompts).

`cp filename.extension newfilename.extension` - Copy a file to a new file (or overwrite destination).
`cp -r foldername newfoldername` - Copy a directory recursively.
`cp <source/path/file.extension> <destination/path/>` - Copy a file from one path to another.
`cp <source/path/file.extension> <destination/path/newname.extension>` - Copy and rename in one command.
`cp -r <source/folderpath> <destination/folderpath>` - Copy a folder to another location.

`mv filename.extension newfilename.extension` - Rename a file.
`mv foldername newfoldername` - Rename a folder.
`mv filename.extension <folderpath>` - Move a file into another folder.
`mv foldername <folderpath>` - Move a folder into another folder.

`tar -cf archivename.tar files folder` - Create an uncompressed tar archive.
`tar -zcf archive.tar.gz files folder` - Create a compressed tar.gz archive.

`tar -xf archive.tar` - Extract a `.tar` archive in the current directory.
`tar -xzf archive.tar.gz` - Extract a `.tar.gz` archive in the current directory.
`tar -xzf archive.tar.gz -C /output/path` - Extract to a specific directory.

## 3. Wildcards & Replacements

`touch file{1,2,3}.txt` - Create `file1.txt`, `file2.txt`, and `file3.txt`.
`touch file-{1..10}.tsx` - Create files from `file-1.tsx` to `file-10.tsx`.
`touch file\?.txt` - Create a file named `file?.txt` (the `?` is escaped, so it is literal).

`ls file-*` - List files that start with `file-`.
`ls file?.tsx` - Match files with exactly one character in place of `?` (for two characters, use `file??.tsx`).

## 4. Output Streams

`stdout` (standard output) - The normal output a command prints (default: terminal screen).
`stderr` (standard error) - Error messages a command prints (default: terminal screen).

`1>` - Redirect standard output (`stdout`) and overwrite the target file.
`1>>` - Redirect standard output and append to the target file.

`echo "Hello there" 1> file.txt` - Write output to `file.txt` (create or overwrite).
`cat file.txt 1> anotherfile.txt` - Write command output to `anotherfile.txt` (overwrite).
`cat file.txt 1>> anotherfile.txt` - Append command output to `anotherfile.txt`.

`2>` - Redirect standard error (`stderr`) and overwrite the target file.
`2>>` - Redirect standard error and append to the target file.

`cat non-existent-file.txt 2> error.txt` - Save errors to `error.txt` (overwrite).
`cat non-existent-file.txt 2>> error.txt` - Append errors to `error.txt`.

`&>` - Redirect both `stdout` and `stderr` to one file.
`cat file.txt non-existent-file.txt &> cat-log.txt` - Save normal output and errors to `cat-log.txt`.

`/dev/null` - Discard output.
`cat file.txt 1> /dev/null` - Ignore standard output (only errors are shown).
`cat file.txt 2> /dev/null` - Ignore errors (only standard output is shown).

## 5. Input Stream

`stdin` (standard input) - The input a command reads (default: keyboard).

`0<` or `<` - Redirect standard input (`stdin`) from a file.

`cat < file.txt` - Read `file.txt` as input and print it.

`grep` - Search for text patterns in files or command output.
`grep "pattern" filename` - Find lines containing `pattern` in `filename`.

## 6. Pipes

`|` (pipe) - Takes the `stdout` (output) of one command and sends it as `stdin` (input) to another command. Works regardless of success/failure of the first command.

`ls -l | grep ".txt"` - List files, then show only lines that contain `.txt`.

## 7. Principle of Least Power

`whoami` - Show the current user.
`cat /etc/passwd` - Show system user account entries.

## 8. Superuser
`sudo <command>` - Run a command with superuser (root) privileges.
`sudo su` - Switch to a root shell.

### Users

`sudo useradd <username>` - Create a new user account.
`sudo passwd <username>` - Set or change the user password.
`sudo useradd -G <groupname> <newuser-name>` - Create a user and assign a group at the same time.

### Groups

`groups <username>` - Show groups the user belongs to.
`sudo groupadd <groupname>` - Create a new group.
`cat /etc/group` - Show all groups.

`sudo usermod --append --groups <groupname> <username>` - Add a user to a group.
`sudo usermod -aG sudo tester` - Add user `tester` to the `sudo` group (on some distros, the admin group is `wheel`).
`sudo visudo` - Open and safely edit the sudoers configuration.

## 9. Group Permissions
`drwxrwxrwx` - Full permission string shown by commands like `ls -l`.

`d` - Directory (`-` means a regular file).
`r` - Read permission.
`w` - Write permission.
`x` - Execute permission.

First `rwx` - Owner (user) permissions.
Second `rwx` - Group permissions.
Third `rwx` - Others permissions.

`sudo chown <user>:<group> <file-or-folder>` - Change owner and group of a file or folder.
`sudo chmod u=rwx,g=rwx,o=rwx <file-or-folder>` - Set read, write, and execute permissions for user, group, and others.
`sudo chmod 777 <file-or-folder>` - Numeric form of the same permission (`rwxrwxrwx`).
