## Interacting with Files

`less filename.txt` - View a file page by page (good for large files).

Useful controls inside `less`:
- `Up/Down Arrow` - Move line by line.
- `Space` - Next page.
- `b` - Previous page.
- `/word` - Search for `word`.
- `n` - Next search result.
- `q` - Quit `less`.

`man <command>` - Show the full manual page for a command.

`cat filename.extension` - Print the full file content to the terminal.

`tail filename.extension` - Show the last lines of a file (default: 10).
`tail -n 3 textfile.txt` - Show the last 3 lines.
`tail -f textfile.txt` - Follow new lines in real time (useful for logs).

`head filename.extension` - Show the first lines of a file (default: 10).
`head -n 3 textfile.txt` - Show the first 3 lines.

`mkdir <foldername>` - Create a new directory.
`mkdir -p <folder1/folder2/folder3>` - Create nested directories in one command.
