## Interacting with Files

## 1. Reading Files

`less filename.txt` - View a file page by page (good for large files).<br>

Useful controls inside `less`:<br>
- `Up/Down Arrow` - Move line by line.
- `Space` - Next page.
- `b` - Previous page.
- `/word` - Search for `word`.
- `n` - Next search result.
- `q` - Quit `less`.

`man <command>` - Show the full manual page for a command.<br>

`cat filename.extension` - Print the full file content to the terminal.<br>

`tail filename.extension` - Show the last lines of a file (default: 10).<br>
`tail -n 3 textfile.txt` - Show the last 3 lines.<br>
`tail -f textfile.txt` - Follow new lines in real time (useful for logs).<br>

`head filename.extension` - Show the first lines of a file (default: 10).<br>
`head -n 3 textfile.txt` - Show the first 3 lines.<br>

## 2. Creating & Moving Files

`mkdir <foldername>` - Create a new directory.<br>
`mkdir -p <folder1/folder2/folder3>` - Create nested directories in one command.<br>

`touch <filename.extension>` - Create a file if it does not exist; if it exists, update its timestamp.<br>

`rm filename.extension` - Delete a file.<br>
`rm -r foldername` - Delete a folder and its contents recursively.<br>
`rm -rf foldername` - Force delete a folder and its contents (no prompts).<br>

`cp filename.extension newfilename.extension` - Copy a file to a new file (or overwrite destination).<br>
`cp -r foldername newfoldername` - Copy a directory recursively.<br>
`cp <source/path/file.extension> <destination/path/>` - Copy a file from one path to another.<br>
`cp file1.ext file2.ext <destination/path>` - Copy multiple files.<br>
`cp -r <source/folderpath> <destination/folderpath>` - Copy a folder to another location.<br>
`cp *.txt /destination/folder/` - Copy all `.txt` files.<br>
`cp *.txt *.pdf /destination/folder/` - Copy all `.txt` and `.pdf` files.<br>

`mv filename.extension newfilename.extension` - Rename a file.<br>
`mv foldername newfoldername` - Rename a folder.<br>
`mv filename.extension <folderpath>` - Move a file into another folder.<br>
`mv file1.ext file2.ext <folderpath>` - Move multiple files into another folder.<br>
`mv foldername <folderpath>` - Move a folder into another folder.<br>
`mv * /destination/folder/` - Move everything in the current directory.<br>
`mv *.log /var/log/archive/` - Move all `.log` files.<br>

`tar -cf archivename.tar files folder` - Create an uncompressed tar archive.<br>
`tar -zcf archive.tar.gz files folder` - Create a compressed tar.gz archive.<br>

`tar -xf archive.tar` - Extract a `.tar` archive in the current directory.<br>
`tar -xzf archive.tar.gz` - Extract a `.tar.gz` archive in the current directory.<br>
`tar -xzf archive.tar.gz -C /output/path` - Extract to a specific directory.<br>

## 3. Wildcards & Replacements

`touch file{1,2,3}.txt` - Create `file1.txt`, `file2.txt`, and `file3.txt`.<br>
`touch file-{1..10}.tsx` - Create files from `file-1.tsx` to `file-10.tsx`.<br>
`touch file\?.txt` - Create a file named `file?.txt` (the `?` is escaped, so it is literal).<br>

`ls file-*` - List files that start with `file-`.<br>
`ls file?.tsx` - Match files with exactly one character in place of `?` (for two characters, use `file??.tsx`).<br>

## 4. Output Streams

`stdout` (standard output) - The normal output a command prints (default: terminal screen).<br>
`stderr` (standard error) - Error messages a command prints (default: terminal screen).<br>

`1>` - Redirect standard output (`stdout`) and overwrite the target file.<br>
`1>>` - Redirect standard output and append to the target file.<br>

`echo "Hello there" 1> file.txt` - Write output to `file.txt` (create or overwrite).<br>
`cat file.txt 1> anotherfile.txt` - Write command output to `anotherfile.txt` (overwrite).<br>
`cat file.txt 1>> anotherfile.txt` - Append command output to `anotherfile.txt`.<br>

`2>` - Redirect standard error (`stderr`) and overwrite the target file.<br>
`2>>` - Redirect standard error and append to the target file.<br>

`cat non-existent-file.txt 2> error.txt` - Save errors to `error.txt` (overwrite).<br>
`cat non-existent-file.txt 2>> error.txt` - Append errors to `error.txt`.<br>

`&>` - Redirect both `stdout` and `stderr` to one file.<br>
`cat file.txt non-existent-file.txt &> cat-log.txt` - Save normal output and errors to `cat-log.txt`.<br>

`/dev/null` - Discard output.<br>
`cat file.txt 1> /dev/null` - Ignore standard output (only errors are shown).<br>
`cat file.txt 2> /dev/null` - Ignore errors (only standard output is shown).<br>

## 5. Input Stream

`stdin` (standard input) - The input a command reads (default: keyboard).<br>

`0<` or `<` - Redirect standard input (`stdin`) from a file.<br>

`cat < file.txt` - Read `file.txt` as input and print it.<br>

`grep` - Search for text patterns in files or command output.<br>
`grep "pattern" filename` - Find lines containing `pattern` in `filename`.<br>
`grep -i "pattern" filename` - Find lines that match `pattern` in `filename`, ignoring case.<br>

## 6. Pipes

`|` (pipe) - Take the `stdout` (output) of one command and send it as `stdin` (input) to another command. A plain pipe does not check whether the first command succeeded; it just passes along whatever was written to standard output.<br>

`ls -l | grep ".txt"` - List files, then show only lines that contain `.txt`.<br>

## 7. Principle of Least Power

`whoami` - Show the current user.<br>
`cat /etc/passwd` - Show system user account entries.<br>

## 8. Superuser

`sudo <command>` - Run a command with superuser (root) privileges.<br>
`sudo su` - Switch to a root shell.<br>
`sudo su <username>` - Switch to `<username>` while keeping much of your current shell environment (`PATH`, variables, etc.); not a full login shell.<br>
`sudo su - <username>` - Switch to `<username>` with a full login environment (PATH, profile scripts, etc.).<br>

### Users

**Manual user creation**<br>

`sudo useradd <username>` - Create a new user account.<br>
`sudo passwd <username>` - Set or change the user password.<br>
`sudo useradd -G <groupname> <username>` - Create a user and assign a group at the same time.<br>

**Automatic user creation**<br>

`sudo adduser <username>` - Create a new user interactively; you are prompted for password and other account details.<br>

### Groups

`groups <username>` - Show groups the user belongs to.<br>
`sudo groupadd <groupname>` - Create a new group.<br>
`cat /etc/group` - Show all groups.<br>

`sudo usermod --append --groups <groupname> <username>` - Add a user to a group.<br>
`sudo usermod -aG sudo tester` - Add user `tester` to the `sudo` group (on some distros, the admin group is `wheel`).<br>
`sudo visudo` - Open and safely edit the sudoers configuration.<br>

## 9. Group Permissions

`drwxrwxrwx` - Full permission string shown by commands like `ls -l`.<br>

`d` - Directory (`-` means a regular file).<br>
`r` - Read permission.<br>
`w` - Write permission.<br>
`x` - Execute permission.<br>

First `rwx` - Owner (user) permissions.<br>
Second `rwx` - Group permissions.<br>
Third `rwx` - Others permissions.<br>

`sudo chown <user>:<group> <file-or-folder>` - Change owner and group of a file or folder.<br>
`sudo chmod u=rwx,g=rwx,o=rwx <file-or-folder>` - Set read, write, and execute permissions for user, group, and others.<br>

## 10. Permission Shortcuts

`sudo chmod 777 <file-or-folder>` - Numeric form of the same permission (`rwxrwxrwx`).<br>
`sudo chmod +x <file-or-folder>` - Add execute permission (`x`) for user, group, and others.<br>
`chmod u+x <file-or-folder>` - Add execute permission for owner (user) only.<br>
`chmod g+x <file-or-folder>` - Add execute permission for group only.<br>
`chmod o+x <file-or-folder>` - Add execute permission for others only.<br>
