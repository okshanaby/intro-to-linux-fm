## Nano

`nano textfile.extension` - Open the file in Nano; if it does not exist yet, Nano creates it when you save.<br>

`Ctrl + o` - Save (write out) your changes.<br>

`Ctrl + x` - Exit the editor (Nano may prompt you to save if there are unsaved changes).<br>

## Vim

`vim textfile.extension` - Open the file in Vim; if the file is new, Vim creates it when you save (`:w`).<br>

**Modes**<br>

`i` - Enter insert mode (edit text). The `Insert` key often does the same.<br>

`Esc` - Leave insert mode and return to normal mode (where you run commands like `:w`).<br>

**Saving and quitting**<br>

`:q` - Quit if there are no unsaved changes (or nothing to save).<br>

`:q!` - Quit without saving (discard changes).<br>

`:qa!` - Quit all windows/tabs without saving (force exit).<br>

`:w` - Save (write) changes.<br>

`:wq` - Save and quit.<br>

**Editing lines**<br>

`:d` - Delete the current line (in command-line mode, after `:`).<br>

In **normal mode** (after `Esc`), `dd` deletes the current line; `5dd` deletes five lines starting at the cursor.<br>

**Help**<br>

`:help tutor` - Open Vim’s built-in help about the tutor (you can also run `vimtutor` in the terminal for the interactive lesson).<br>
