## Nano

`nano textfile.extension` - Open the file in Nano; if it does not exist yet, Nano creates it when you save.

`Ctrl + o` - Save (write out) your changes.

`Ctrl + x` - Exit the editor (Nano may prompt you to save if there are unsaved changes).

## Vim

`vim textfile.extension` - Open the file in Vim; if the file is new, Vim creates it when you save (`:w`).

**Modes**

`i` - Enter insert mode (edit text). The `Insert` key often does the same.

`Esc` - Leave insert mode and return to normal mode (where you run commands like `:w`).

**Saving and quitting**

`:q` - Quit if there are no unsaved changes (or nothing to save).

`:q!` - Quit without saving (discard changes).

`:qa!` - Quit all windows/tabs without saving (force exit).

`:w` - Save (write) changes.

`:wq` - Save and quit.

**Editing lines**

`:d` - Delete the current line (in command-line mode, after `:`).

In **normal mode** (after `Esc`), `dd` deletes the current line; `5dd` deletes five lines starting at the cursor.

**Help**

`:help tutor` - Open Vim’s built-in help about the tutor (you can also run `vimtutor` in the terminal for the interactive lesson).
